Lauren's Wellness Tracker — v1.0

A personal wellness tracker built for Lauren, designed around endometriosis management, nutrition tracking, and metabolic support.

What it does
Nutrition logging — photo meal logging with AI macro estimation, manual entry, and quick-add high-protein foods
Macro tracking — personalised daily targets for calories, protein, fat, carbs, and water
Weight tracking — daily logging with progress toward goal, realistic timeline, and history
Sleep logging — total, deep, and REM tracking with colour-coded targets
Supplement checklist — daily tracking with timing notes and soy allergy flags
AI health assistant — Claude-powered chat that knows Lauren's profile, condition, and allergy
Allergy note

Lauren has an anaphylactic soy protein allergy. The app flags soy risks throughout — in supplements, in photo meal analysis, and in the AI assistant responses.

How to use

Open the URL in Safari on iPhone. On first load, complete the setup screen (takes 2 minutes). To add to iPhone home screen: tap Share → Add to Home Screen.

Tech

Single file HTML/CSS/JavaScript app. No installation required. Runs entirely in the browser. Data saves to browser local storage. Google Drive sync is planned for v2.

Version history
